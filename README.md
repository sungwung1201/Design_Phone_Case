# 팀 작업 타임라인 및 진행 현황

로봇팔 기반 커스텀 드로잉 시스템 프로젝트는 **2026년 4월 30일부터 2026년 5월 8일까지 앱, 서버, 로봇, 알고리즘 등 기능 개발을 연속적으로 진행**했다.

앱, 서버, 로봇 구동 및 알고리즘 등 주요 기능은 **2026년 5월 8일 기준으로 마무리**되었으며, **2026년 5월 8일부터 2026년 5월 11일까지 PPT, 전체 플로우차트, 시스템 아키텍처, 발표 대본 정리**를 완료했다. 또한 **2026년 5월 11일에는 협동구간 설정 및 안전 범위 검토를 진행하고 마무리**했다.

## 현재 진행 상태 요약

- 2026년 4월 30일부터 2026년 5월 8일까지 앱, 서버, 로봇, 알고리즘 기능 개발을 연속적으로 진행했다.
- 2026년 5월 8일 기준 코드 개발 및 로봇 구동 관련 기능은 마무리되었다.
- 서버와 로봇 간 파일 전송, DB 상태 변경, ROS2 Service 기반 로봇 제어 구조를 완성했다.
- 서버 관리자 웹페이지 및 실시간 주문 상태 조회 시스템을 구축했다.
- Flask API와 ROS2 자동 실행 흐름을 연동하여 주문 감지 시 자동 드로잉이 가능하도록 구성했다.
- 주문 취소 요청, 작업 중단, 작업 완료, 외력 중단 등 예외 상태를 DB 상태값과 API 흐름에 반영했다.
- 외력 발생 시 서버 관리자 웹페이지에서 알림창을 띄우도록 구성했다.
- 펜 좌표, 케이스 좌표, HOME 초기 위치 세팅 및 그리퍼 제어를 완료했다.
- 이미지 기반 경로 추출, 중심선 기반 드로잉, Path 연결, No-Lift Drawing, MoveLine 기반 제어를 적용했다.
- 2026년 5월 8일부터 2026년 5월 11일까지 PPT, 전체 플로우차트, 시스템 아키텍처, 발표 대본 정리를 완료했다.
- 2026년 5월 11일 협동구간 설정 및 안전 범위 검토를 완료했다.
- 남은 작업은 최종 발표 및 시연 리허설이다.

## 시스템 진행 흐름

```text
이미지 입력
↓
이미지 전처리
↓
색상별 마스크 생성
↓
드로잉 경로 추출
↓
중심선 기반 Path 생성
↓
픽셀 좌표 → 로봇 물리 좌표 변환
↓
Path 연결 및 No-Lift Drawing 적용
↓
MoveLine 기반 로봇팔 드로잉 수행
↓
작업 완료 상태 서버/DB 반영
```

## 주요 구현 기능

### 앱

- 사용자 시작 화면 UI 구성
- 기기 선택, 케이스 타입, 범퍼 색상 선택 UI 구현
- 캔버스 드로잉 UI 구현
- 브러시 색상/굵기 조절 및 실행 취소(Undo) 기능 구현
- 이미지 업로드 및 캔버스 반영 기능 구현
- 템플릿/직접 그리기 기반 도안 입력 흐름 구성
- 사용자가 만든 도안을 `strokeData` 및 이미지 형태로 서버에 전달하는 구조 구현
- 이미지 업로드 및 서버 전송 로직 구현
- 주문 정보와 도안 데이터를 포함한 결제/주문 전송 흐름 구현
- 작업 상태 확인 및 폴링 완료 알림 로직 구현
- 주문 ID 기반 상태 추적 및 세션 유지 로직 구현
- 진행률, 예상 시간, 단계 표시를 포함한 사용자 상태 확인 UI 구현
- 취소 요청, 취소 완료, 작업 완료 상태에 따른 UI 분기 처리 구현
- 외부 충격 정지(impact stop) 등 예외 상황에 대한 사용자 안내 UI 구현
- 취소 정책, 확인 모달, 상태별 버튼 제어 등 예외처리 UX 반영
- 전체 주문 흐름 기준 UI/UX 점검 및 화면 템포 조정 완료


### 서버

- API 통신 포트 및 DB 구조 설계
- 이미지 수신 및 로컬 저장 로직 구현
- SQLite 데이터 INSERT 연동
- 주문 상태값 및 DB 테이블 구조 정리
- 서버 ↔ 로봇 파일 전송 파이프라인 구현
- 로봇 작업 완료 PATCH API 구현
- 서버 관리자 웹페이지 구축
- 실시간 주문 상태 조회 기능 구현
- SQLite 주문 데이터 시각화 환경 구축
- Flask API ↔ ROS2 자동 실행 구조 연동
- 주문 감지 기반 자동 드로잉 실행 구조 구현
- 주문 취소 요청 API 및 DB 상태 변경 로직 구현
- 취소 요청 발생 시 로봇 작업 중단 흐름과 서버 상태값 연동
- 작업 완료, 작업 중단, 취소 완료 등 상태별 PATCH/조회 흐름 정리
- 외력 발생 시 로봇 중단 상태를 서버 로그 및 DB 상태값에 반영하는 구조 구현
- 서버 관리자 웹페이지 외력 중단 알림창 구현
- 실시간 상태 폴링을 통해 주문 상태와 로봇 상태를 관리자 화면에 반영
- DB 상태 변경 및 오류 점검 완료

### 로봇 / 알고리즘

- 픽셀 좌표 → 로봇 물리 좌표 변환
- M0609 초기 위치 및 기본 이동 좌표 세팅
- ROS2 MoveLine 기반 로봇 제어 연동
- 그리퍼 I/O 제어 연동
- 펜 UP/DOWN Z축 하강/상승 루프 구현
- Canny Edge, Contour, Skeleton 방식 검토
- Boundary 기반 중심선 추출 알고리즘 개선
- Path Boundary Nearest Midline 알고리즘 적용
- Catmull-Rom 보간 적용
- Path 연결 및 No-Lift Drawing 로직 적용
- MoveSplineTask 검토 후 MoveLine 단일화
- 펜 좌표 및 케이스 좌표 캘리브레이션
- 로봇 시작 시 HOME 복귀 안정화
- 디버그 이미지 저장 및 경로 검증 로직 적용
- 협동구간 설정 및 안전 범위 검토 완료

### 발표 자료

- 프로젝트 목차 및 시스템 구조 기획
- 시스템 아키텍처 정리
- 전체 플로우차트 작성
- ROS2 Service 통신 구조 정리
- 로봇 구동 알고리즘 페이지 작성
- PPT 점검 및 발표 흐름 정리 완료
- 전체 플로우차트 및 시스템 아키텍처 정리 완료
- 발표 대본 최종 정리 완료
- 시연 영상 편집 및 PPT 삽입 완료

## 최종 목표

사용자가 캔버스에 그림을 입력하거나 이미지를 업로드하면, 서버가 이미지를 수신하고 로봇 제어 코드가 해당 경로를 변환하여 로봇팔이 폰케이스 위에 자동으로 그림을 그리는 풀-사이클 시스템을 완성하는 것을 목표로 한다.

최종 시스템은 다음 흐름으로 동작한다.

```text
사용자 입력
↓
앱에서 이미지 서버 전송
↓
서버에서 이미지 저장 및 DB 상태 갱신
↓
로봇 코드에서 주문 감지
↓
이미지 기반 드로잉 경로 생성
↓
로봇 물리 좌표 변환
↓
펜 픽업
↓
케이스 위 드로잉
↓
펜 반납
↓
완성 케이스 배출
↓
작업 완료 상태 서버 반영
```
