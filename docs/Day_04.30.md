# 폰꾸꾸 시스템 구체화

## 1. 개요

본 문서는 로봇팔 기반 태블릿 케이스 커스텀 드로잉 시스템의 전체 작업 흐름, 시스템 구성 요소, 작업 공간 배치, 앱 기능, 서버 처리 과정, 로봇 동작 시퀀스, 지그 설계 방향, 좌표계 기준, 핵심 구현 포인트를 정리한 문서이다.

이 시스템은 사용자가 앱에서 직접 그림을 그리거나 이미지를 업로드하면, 서버가 해당 이미지를 로봇이 따라갈 수 있는 좌표 데이터로 변환하고, 두산 M0609 로봇팔이 태블릿 케이스 위에 자동으로 그림을 그리는 구조이다.

최종적으로는 단순히 그림만 그리는 로봇이 아니라, 케이스 이송, 지그 정렬, 펜 파지, 자동 드로잉, 펜 반납, 완성품 배출까지 포함하는 자동 제작 시스템을 목표로 한다.

## 2. 전체 작업 흐름

```text
사용자 앱 접속
↓
그림 직접 그리기 또는 이미지 업로드
↓
서버가 이미지 수신
↓
이미지 전처리
↓
드로잉 좌표 생성
↓
앱에서 미리보기 확인
↓
사용자가 제작 시작
↓
로봇팔 HOME 위치 이동
↓
로봇팔이 태블릿 케이스 대기 위치로 이동
↓
그리퍼로 태블릿 케이스 파지
↓
태블릿 케이스를 지그 위치로 이동
↓
태블릿 케이스를 지그 위에 내려놓음
↓
L자 기준벽에 맞춰 케이스 정렬
↓
로봇팔이 펜/마커 거치대로 이동
↓
그리퍼로 펜 또는 마커 파지
↓
드로잉 시작 위치로 이동
↓
펜을 케이스 표면에 접촉
↓
생성된 좌표 경로를 따라 드로잉
↓
드로잉 완료 후 펜 올림
↓
펜 또는 마커 거치대에 반납
↓
완성된 태블릿 케이스 파지
↓
완성품 보관 위치로 이동
↓
케이스 내려놓기
↓
로봇팔 HOME 위치 복귀
↓
앱에 작업 완료 표시
```

## 4. 작업 공간 배치

작업 공간은 크게 4개 구역으로 나눈다.

```text
A구역: 태블릿 케이스 대기 위치
B구역: 고정 지그 및 드로잉 위치
C구역: 펜/마커 거치대
D구역: 완성품 보관 위치
```

로봇팔은 다음 순서로 움직인다.

```text
A → B → C → B → C → B → D → HOME
```

각 구역의 역할은 다음과 같다.

| 구역 | 역할 |
|---|---|
| A구역 | 작업 전 태블릿 케이스가 대기하는 위치 |
| B구역 | 케이스를 고정하고 실제 드로잉을 수행하는 위치 |
| C구역 | 펜 또는 마커를 보관하고 파지하는 위치 |
| D구역 | 작업이 완료된 케이스를 내려놓는 위치 |

## 5. 앱 기능

앱은 사용자가 원하는 디자인을 입력하고 작업을 시작하는 역할을 한다.

주요 기능은 다음과 같다.

```text
이미지 업로드
직접 그림 그리기
문구 입력
드로잉 미리보기 확인
제작 시작 버튼
작업 진행 상태 표시
작업 완료 알림
오류 알림
```

작업 전에는 서버가 변환한 드로잉 결과를 미리보기로 보여준다.

사용자는 미리보기를 확인한 뒤 제작을 시작한다.

## 6. 서버 처리 과정

서버는 사용자가 입력한 이미지를 로봇팔이 따라갈 수 있는 좌표 데이터로 변환한다.

```text
이미지 수신
↓
이미지 크기 조정
↓
흑백 변환
↓
외곽선 추출
↓
노이즈 제거
↓
좌표 점 추출
↓
태블릿 케이스 작업 영역에 맞게 스케일링
↓
로봇 좌표계로 변환
↓
로봇 제어 시스템으로 전달
```

서버 처리 과정에서 가장 중요한 부분은 이미지 좌표를 실제 로봇 좌표로 변환하는 것이다.

이미지에서 추출한 좌표는 픽셀 단위이기 때문에, 태블릿 케이스의 실제 크기와 드로잉 가능 영역을 기준으로 스케일링해야 한다.

## 8. 지그 설계 방향

태블릿 케이스는 넓고 크기 때문에 드로잉 중 위치가 흔들리면 결과물이 틀어진다.

따라서 케이스를 항상 같은 기준 위치에 맞춰주는 지그가 필요하다.

추천 지그 구조는 다음과 같다.

```text
L자 기준벽 + 미끄럼방지 패드 + 조절식 고정 블록
```

지그 역할은 다음과 같다.

| 요소 | 역할 |
|---|---|
| L자 기준벽 | 케이스 기준 위치 고정 |
| 미끄럼방지 패드 | 드로잉 중 케이스 밀림 방지 |
| 조절식 고정 블록 | 케이스 크기 차이 보정 |
| 고무/스펀지 패드 | 케이스 손상 방지 및 밀착 |

로봇이 케이스를 지그 위에 내려놓은 뒤, 그리퍼로 살짝 밀어 L자 기준벽에 붙이면 최종 위치를 일정하게 맞출 수 있다.

## 9. 좌표계 기준

로봇이 정확히 그림을 그리기 위해 기준 좌표를 정해야 한다.

```text
로봇 기준 원점 = 지그의 왼쪽 아래 기준 모서리
드로잉 영역 = 태블릿 케이스 안쪽 여백을 제외한 영역
```

예시 기준은 다음과 같다.

```text
지그 기준점: P0
드로잉 시작점: P0에서 X 방향 30mm, Y 방향 40mm
드로잉 가능 영역: 가로 180mm, 세로 240mm
펜 접촉 높이: z_draw
펜 이동 높이: z_safe
```

드로잉할 때는 `z_draw` 높이로 이동하고, 선을 그리지 않는 구간에서는 `z_safe` 높이로 올라간 뒤 이동한다.

## 10. 좌표 변환 개념

이미지 좌표를 로봇 좌표로 변환하기 위해서는 다음 기준이 필요하다.

```text
이미지 가로 픽셀 크기
이미지 세로 픽셀 크기
실제 드로잉 영역 가로 길이
실제 드로잉 영역 세로 길이
지그 기준 원점
로봇 좌표계 방향
```

기본 변환 개념은 다음과 같다.

```text
이미지 X 픽셀 → 로봇 X 좌표
이미지 Y 픽셀 → 로봇 Y 좌표
펜 접촉 여부 → 로봇 Z 좌표
```

예를 들어 이미지의 한 점이 `(px, py)`라면, 이를 실제 드로잉 영역 크기에 맞게 변환하여 `(x_robot, y_robot, z_draw)` 좌표로 바꾼다.

선을 그리지 않고 이동해야 하는 구간에서는 Z축을 `z_safe`로 올린 뒤 이동한다.

## 11. 핵심 구현 포인트

| 핵심 포인트 | 이유 |
|---|---|
| 케이스 파지 | 태블릿 케이스를 안정적으로 이동해야 함 |
| 지그 정렬 | 케이스 위치가 매번 같아야 그림 위치가 맞음 |
| 펜 파지 | 펜 각도와 높이가 일정해야 선 품질이 유지됨 |
| 좌표 변환 | 이미지 좌표를 로봇 좌표로 바꿔야 함 |
| 펜 접촉 제어 | 너무 세게 누르면 충돌, 약하면 선 끊김 발생 |
| 경로 분리 | 선을 그리는 구간과 이동 구간을 구분해야 함 |
| 완료 후 배출 | 자동 제작 공정 느낌을 완성함 |

## 12. 예상 문제와 해결 방안

| 예상 문제 | 원인 | 해결 방안 |
|---|---|---|
| 케이스가 밀림 | 고정 부족, 펜 압력 과다 | 미끄럼방지 패드, L자 지그 사용 |
| 그림 위치가 틀어짐 | 케이스 위치 오차 | 지그 기준점 고정, 로봇 좌표 보정 |
| 펜 선이 끊김 | 펜 높이 과다, 잉크 부족 | z_draw 보정, 펜 테스트 추가 |
| 선이 너무 진함 | 펜 압력 과다 | Z축 오프셋 조정 |
| 펜을 못 잡음 | 펜 거치대 위치 불안정 | 펜 거치대 고정, 파지 위치 반복 테스트 |
| 케이스 파지 실패 | 케이스가 얇고 넓음 | 그리퍼 패드 부착, 이동 속도 낮춤 |
| 이미지가 너무 복잡함 | 좌표가 너무 많음 | 외곽선 단순화, 정밀도 선택 기능 추가 |

## 13. 우선 구현 순서

처음부터 전체 기능을 한 번에 구현하지 않고 단계별로 진행한다.

```text
1단계: 태블릿 케이스 지그 제작
2단계: 케이스 파지 및 지그 배치 테스트
3단계: 펜/마커 거치대 제작
4단계: 펜 파지 테스트
5단계: 직선 드로잉 테스트
6단계: 사각형, 원, 간단한 도형 테스트
7단계: 서버 좌표 데이터 연동
8단계: 앱에서 이미지 업로드 및 미리보기 구현
9단계: 사용자 이미지 기반 드로잉 테스트
10단계: 완성품 배출 동작 추가
```

처음 테스트 도안은 복잡한 이미지가 아니라 아래 순서로 진행한다.

```text
직선 → 사각형 → 원 → 이름/이니셜 → 간단한 아이콘 → 사용자 이미지
```

## 15. 최종 목표

최종 목표는 사용자가 앱에서 원하는 디자인을 입력하면, 로봇팔이 태블릿 케이스를 지그에 배치하고, 펜 또는 마커로 그림을 그린 뒤, 완성품을 보관 위치로 이동시키는 것이다.

즉, 본 프로젝트는 단순히 그림을 그리는 로봇이 아니라 다음 공정을 포함하는 자동 제작 시스템을 목표로 한다.

```text
이미지 입력
↓
좌표 변환
↓
케이스 이송
↓
지그 정렬
↓
펜 파지
↓
자동 드로잉
↓
펜 반납
↓
완성품 배출
```

## 16. 요약

폰꾸꾸 시스템은 사용자가 업로드한 이미지나 직접 그린 그림을 기반으로 태블릿 케이스 위에 자동으로 드로잉하는 로봇팔 기반 커스텀 제작 시스템이다.

핵심은 이미지 처리, 좌표 변환, 로봇 경로 생성, 지그 정렬, 펜 접촉 제어이다.

초기 구현에서는 복잡한 이미지보다 직선, 사각형, 원, 이니셜 등 단순 도안부터 테스트하는 것이 적합하다.

최종적으로는 앱 입력부터 로봇 드로잉, 완성품 배출까지 연결된 자동 제작 시스템을 구현하는 것을 목표로 한다.
