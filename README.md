## 현재 진행 사항

현재는 로봇팔 기반 커스텀 드로잉 시스템의 기본 동작을 구현하고 있으며, 이미지 입력부터 드로잉 좌표 생성, 로봇 동작 연결까지 단계적으로 개발 중이다.

주요 진행 방향은 다음과 같다.

```text
이미지 입력
↓
이미지 전처리
↓
외곽선 추출
↓
드로잉 좌표 생성
↓
로봇 좌표 변환
↓
로봇팔 드로잉 동작 수행
```

## 요약

현재 프로젝트는 로봇팔이 사용자의 그림 또는 이미지를 기반으로 케이스 위에 자동 드로잉하는 시스템을 개발하는 단계이다.

프론트엔드에서는 캔버스 드로잉 UI, 이미지 업로드, 사용자 시작 화면, 작업 상태 확인 기능을 구현한다.

서버에서는 이미지 수신, 로컬 저장, SQLite 데이터 연동, 로봇 파일 전송, 작업 완료 API를 구현한다.

로봇/알고리즘 파트에서는 OpenCV 흑백 변환, Canny 외곽선 추출, 픽셀 좌표를 로봇 물리 좌표로 변환하는 기능, 펜 UP/DOWN 제어, 경로 최적화 기능을 구현한다.

최종적으로는 사용자가 그림을 입력하면 서버가 좌표를 생성하고, 로봇팔이 해당 좌표를 따라 케이스 위에 그림을 그린 뒤 작업 완료 신호를 반환하는 풀-사이클 시스템을 완성하는 것을 목표로 한다.
