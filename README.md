## 현재 진행 사항

현재는 로봇팔 기반 커스텀 드로잉 시스템의 기본 동작을 구현하고 있으며, 이미지 입력부터 드로잉 좌표 생성, 로봇 동작 연결까지 단계적으로 개발 중이다.

주요 진행 방향은 다음과 같다.

```text
이미지 입력
↓
이미지 전처리
↓
외곽선 추출
↓
드로잉 좌표 생성
↓
로봇 좌표 변환
↓
로봇팔 드로잉 동작 수행
```

## TODO LIST

### 1. 색깔 추가 기능

사용자가 원하는 색상을 선택할 수 있도록 색깔 추가 기능을 구현한다.

예상 기능은 다음과 같다.

```text
색상 선택
선 색상 변경
색상별 드로잉 경로 구분
펜 또는 마커 교체 동작 연동
```

---

### 2. 사용자 시작 화면 UI

사용자가 서비스를 쉽게 시작할 수 있도록 초기 화면 UI를 구성한다.

필요한 기능은 다음과 같다.

```text
서비스 시작 버튼
이미지 업로드 버튼
직접 그리기 버튼
문구 입력 버튼
제작 시작 버튼
작업 상태 확인 화면
```

---

### 3. 서버 관리자 UI

관리자가 서버 상태와 작업 진행 상황을 확인할 수 있는 관리자 화면을 구현한다.

필요한 기능은 다음과 같다.

```text
현재 작업 상태 확인
업로드된 이미지 확인
변환된 좌표 데이터 확인
로봇 연결 상태 확인
작업 성공/실패 로그 확인
오류 발생 시 알림 표시
```

---

### 4. 그림 알고리즘 상세 구현

사용자가 업로드한 이미지나 직접 그린 그림을 로봇이 따라 그릴 수 있도록 알고리즘을 구체화한다.

구현해야 할 핵심 기능은 다음과 같다.

```text
이미지 크기 조정
흑백 변환
외곽선 추출
노이즈 제거
좌표 점 추출
좌표 단순화
이미지 좌표를 로봇 좌표로 변환
펜 이동 경로 생성
펜 내림/올림 구간 분리
```

## 요약

현재 프로젝트는 로봇팔이 사용자의 그림 또는 이미지를 기반으로 케이스 위에 자동 드로잉하는 시스템을 개발하는 단계이다.

앞으로는 그림 알고리즘을 구체화하고, 사용자 UI와 서버 관리자 UI를 구현한 뒤, 색깔 추가 기능까지 확장하는 것을 목표로 한다.
