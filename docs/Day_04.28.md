# 협동로봇 실습 기록

## 1. 동기 / 비동기 방식 차이

### 동기 방식 Sync

동기 방식은 명령을 순서대로 하나씩 실행하는 방식이다.  
이전 작업이 끝나야 다음 작업을 수행한다.

### 흐름

```text
[사용자] → MoveJ → 완료 → MoveL → 완료
```

즉, 로봇 동작이 순차적으로 실행된다.

### 장점

- 명령이 순서대로 실행되어 안정성이 높다.
- 충돌 가능성이 상대적으로 낮다.
- 동작 결과를 예측하기 쉽다.
- 문제가 생겼을 때 디버깅하기 쉽다.

### 단점

- 이전 작업이 끝날 때까지 기다려야 하므로 속도가 느릴 수 있다.
- 대기 시간이 발생하여 작업 효율이 떨어질 수 있다.
- 연속 동작이 끊겨 보일 수 있다.

---

### 비동기 방식 Async

비동기 방식은 이전 작업이 완전히 끝나기 전에 다음 작업을 실행할 수 있는 방식이다.  
여러 명령이 동시에 또는 겹쳐서 실행될 수 있다.

### 흐름

```text
[사용자] → MoveJ
        → MoveL
```

즉, 동작이 병렬적으로 처리될 수 있다.

### 장점

- 여러 작업을 동시에 처리할 수 있어 속도가 빠르다.
- 대기 시간을 줄일 수 있다.
- 동작이 자연스럽게 이어질 수 있다.
- 작업 효율이 높아질 수 있다.

### 단점

- 명령이 겹치면서 충돌 위험이 생길 수 있다.
- 실행 결과를 예측하기 어렵다.
- 문제가 발생했을 때 원인을 찾기 어렵다.

---

## 2. 썬기어 중앙 삽입 미션 적용

### 미션 목표

썬기어 하나를 집어서 중앙 위치에 정확히 삽입하는 작업을 수행하였다.  
이 작업에서는 로봇의 이동 경로, 그리퍼 동작, 접근 방향, 안전한 위치 설정이 중요하다.

### 작업 순서

```text
[START]
↓
[Gripper Open]
↓
[Home Position 이동]
↓
[집기 위치 상단 이동]
↓
[집기 위치로 하강]
↓
[Gripper Close / 물체 집기]
↓
[상단으로 상승]
↓
[이송 위치로 이동]
↓
[놓기 위치로 하강]
↓
[Gripper Open / 물체 놓기]
↓
[상단으로 상승]
↓
[Home 복귀]
↓
[END]
```

## 3. MoveJ와 MoveL 비교

### 실험 목적

MoveJ와 MoveL이 동일한 시작점과 목표점을 가지더라도 서로 다른 움직임을 보이는 이유를 확인하였다.  
각 명령의 제어 원리를 기준으로 로봇의 이동 경로 차이를 비교하였다.

---

### MoveJ 관절 기준 이동

MoveJ는 로봇의 각 관절을 기준으로 목표 위치까지 이동하는 방식이다.

### 특징

- 목표 위치까지 빠르게 이동할 수 있다.
- 각 관절이 동시에 회전하면서 이동한다.
- 중간 경로가 직선이 아니라 곡선 형태가 될 수 있다.
- 최종 위치만 맞으면 되기 때문에 중간 경로 예측이 어렵다.
- 로봇 팔의 움직임이 자연스럽게 휘어질 수 있다.
- 장애물을 우회하는 형태의 움직임이 나올 수 있다.

### 적합한 상황

MoveJ는 정확한 직선 경로가 필요하지 않고, 빠르게 위치를 이동해야 할 때 적합하다.  
예를 들어 Home 위치에서 작업 위치 상단으로 이동하거나, 작업 후 다시 대기 위치로 복귀할 때 사용할 수 있다.

---

### MoveL 직선 이동

MoveL은 로봇의 TCP가 공간상에서 직선으로 이동하는 방식이다.

### 특징

- TCP가 시작점에서 목표점까지 직선 경로로 이동한다.
- 경로가 고정되어 있어 예측하기 쉽다.
- 직선 경로를 유지해야 하므로 속도가 제한될 수 있다.
- 경로 중간에 장애물이 있으면 충돌 위험이 있다.
- 정밀한 접근, 하강, 삽입 동작에 적합하다.

### 적합한 상황

MoveL은 물체를 집기 위해 수직으로 내려가거나, 썬기어를 중앙 구멍에 정확히 삽입하는 단계에 적합하다.  
단, 중간 경로에 장애물이 있으면 그대로 충돌할 수 있으므로 접근 전 위치 설정이 중요하다.

---

## 4. MoveJ와 MoveL 차이 요약

| 구분 | MoveJ | MoveL |
|---|---|---|
| 이동 기준 | 관절 기준 | TCP 직선 경로 기준 |
| 경로 형태 | 곡선 형태 가능 | 직선 경로 유지 |
| 속도 | 빠름 | 상대적으로 느림 |
| 예측성 | 중간 경로 예측 어려움 | 경로 예측 쉬움 |
| 충돌 위험 | 상대적으로 낮음 | 경로상 장애물 있으면 높음 |
| 적합한 작업 | 위치 이동 | 정밀 접근, 삽입, 하강 |

---

## 5. 썬기어 삽입 작업에서의 적용

썬기어를 중앙에 삽입하는 작업에서는 MoveJ와 MoveL을 상황에 맞게 나누어 사용하는 것이 좋다.

작업 위치 근처까지 이동할 때는 MoveJ를 사용하고, 정확히 집거나 삽입하기 위해 수직으로 접근할 때는 MoveL을 사용하는 방식이 적합하다.

### 적용 예시

```text
Home Position → 집기 위치 상단 이동: MoveJ
집기 위치 상단 → 집기 위치 하강: MoveL
물체 집기 후 상승: MoveL
집기 위치 상단 → 이송 위치 상단 이동: MoveJ
이송 위치 상단 → 놓기 위치 하강: MoveL
물체 놓기 후 상승: MoveL
상단 위치 → Home 복귀: MoveJ
```

이렇게 구성하면 빠른 이동과 정밀한 삽입을 모두 만족할 수 있다.

## 6. 오늘 배운 내용 정리

### 협동로봇

협동로봇은 사람과 같은 공간에서 함께 작업할 수 있도록 설계된 로봇이다.  
일반 산업용 로봇과 달리 충돌 감지, 힘 제어, 속도 제한 등의 기능을 통해 사람과 가까운 환경에서도 사용할 수 있다.

하지만 협동로봇도 로봇이기 때문에 항상 안전하게 다뤄야 한다.  
실습 시에는 낮은 속도로 조작하고, 비상정지 버튼 위치를 확인해야 한다.

---

### 두산 M0609

이번 수업에서는 두산로보틱스의 M0609 모델을 사용하였다.  
M0609는 6축 다관절 협동로봇이다.

충돌 감지, 힘 제어, 순응 제어 등의 기능을 사용할 수 있으며, 정밀한 조립이나 이송 작업에 활용할 수 있다.

---

### 주요 구성품

두산 협동로봇은 크게 티치펜던트, 컨트롤러, 매니퓰레이터로 구성된다.

- 티치펜던트: 로봇을 조작하고 설정하는 장치
- 컨트롤러: 로봇의 움직임을 제어하고 외부 장비와 통신하는 장치
- 매니퓰레이터: 실제 로봇 팔이며, 끝단에 그리퍼나 공구를 장착하는 부분

---

### 좌표계

로봇 조작에는 조인트 좌표계와 태스크 좌표계가 사용된다.

조인트 좌표계는 6개 관절 각도로 로봇 자세를 표현한다.

```python
posj(J1, J2, J3, J4, J5, J6)
```

태스크 좌표계는 TCP의 위치와 자세를 X, Y, Z, A, B, C로 표현한다.

```python
posx(X, Y, Z, A, B, C)
```

BASE 좌표계는 로봇 베이스 기준이고, TOOL 좌표계는 로봇 끝단 TCP 기준이다.

---

### 로봇 조작 방법

로봇 조작 방법에는 조그, 이동, 핸드가이딩이 있다.

- 조그: 로봇을 조금씩 움직이며 위치를 찾을 때 사용
- 이동: 목표 좌표나 관절 값을 알고 있을 때 사용
- 핸드가이딩: 사용자가 직접 로봇을 잡고 자세를 바꾸는 기능

---

### TCP와 툴 설정

TCP는 Tool Center Point의 약자로, 로봇 끝단 공구의 기준점이다.  
그리퍼나 공구를 장착하면 TCP를 정확히 설정해야 원하는 위치에서 작업할 수 있다.

툴 무게 설정도 중요하다.  
툴 무게가 잘못 설정되면 로봇이 이를 충돌이나 외력으로 잘못 인식할 수 있다.

---

### 특이점

특이점은 로봇이 특정 자세에서 움직임을 계산하기 어려워지는 상태이다.  
특이점 근처에서는 로봇 동작이 불안정해질 수 있다.

따라서 특이점 근처에서는 저속으로 조작하고, 필요하면 MoveJ나 특이점 회피 옵션을 사용해야 한다.

---

### RG2 그리퍼

수업에서는 OnRobot RG2 그리퍼를 사용하였다.  
RG2 그리퍼는 물체를 잡거나 놓는 작업에 사용된다.

그리퍼는 로봇 컨트롤러의 DO, DI 신호를 통해 Grip과 Release 동작을 수행한다.

---

### 서브 프로그램

서브 프로그램은 반복되는 작업을 따로 작성해두고 필요할 때 호출하는 기능이다.  
Grip, Release, 특정 위치 이동 같은 동작을 서브 프로그램으로 만들면 프로그램을 더 깔끔하게 작성할 수 있다.

## 8. 결론

이번 실습을 통해 협동로봇의 기본 구조와 이동 명령의 차이를 확인하였다.

MoveJ는 빠른 위치 이동에 적합하고, MoveL은 정밀한 직선 접근이나 삽입 동작에 적합하다.  
썬기어를 중앙에 삽입하는 작업에서는 두 명령을 함께 사용하는 것이 효율적이다.

작업 위치 근처까지는 MoveJ로 이동하고, 집기와 삽입처럼 정확도가 중요한 단계에서는 MoveL을 사용하는 방식이 적합하다.

또한 라멘 제조 프로젝트에서는 면 물기 제거처럼 반복적인 동작을 협동로봇으로 재현할 수 있음을 확인하였다.
